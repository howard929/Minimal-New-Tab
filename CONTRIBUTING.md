# Contributing

[English](CONTRIBUTING.md) | [简体中文](CONTRIBUTING.zh-CN.md)

Thank you for your interest in improving Minimal New Tab.

## Before contributing

Please keep the project goals in mind:

- Local-first
- Minimal UI
- No advertising
- No unnecessary telemetry
- Request the minimum browser permissions needed
- Keep optional privacy-sensitive features opt-in
- Preserve non-commercial licensing

## Issues

When reporting a bug, include:

- Edge version
- Operating system
- Minimal New Tab version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots when useful

Do not include passwords, private URLs, account tokens, or other sensitive information.

## Pull requests

1. Fork the repository.
2. Create a focused branch.
3. Keep changes small and clearly scoped.
4. Test the unpacked extension in Microsoft Edge.
5. Describe what changed and why.
6. Confirm that the contribution is compatible with the repository's PolyForm Noncommercial License 1.0.0.

By submitting a contribution, you agree that your contribution may be distributed under the repository's current license.

## Style

- Prefer plain HTML, CSS, and JavaScript unless a dependency clearly provides meaningful value.
- Avoid adding remote code or third-party analytics.
- Keep UI strings understandable and concise.
- Preserve compatibility with Manifest V3.
