# Security Policy / 安全政策

## English

If you discover a security or privacy issue, please avoid publishing sensitive exploit details in a public issue.

For ordinary low-risk bugs, use GitHub Issues.

For a vulnerability that could expose browsing data, local files, extension storage, or browser permissions, contact the maintainer privately through the contact method listed on the GitHub profile or future project security contact.

Please include the affected version, reproduction steps, and potential impact.

## 简体中文

如果你发现安全或隐私问题，请不要直接在公开 Issue 中发布可能被滥用的完整漏洞细节。

普通低风险 Bug 可以直接使用 GitHub Issues。

如果问题可能导致浏览数据、本地文件、扩展存储或浏览器权限被不当访问，请优先通过 GitHub 个人资料中的联系方式，或未来项目公布的安全联系方式私下联系维护者。

请尽量提供受影响版本、复现步骤和可能影响。
